Wat het project was

Een responsive portfolio-website, gebouwd met HTML, CSS en JavaScript. De website die je nu bekijkt is het resultaat: ik heb de pagina opgebouwd uit losse secties, de vormgeving in een aparte CSS-bestand gezet en de kleuren via CSS-variabelen gedefinieerd, zodat ik ze op één plek kan aanpassen.

Wat ik heb geleerd

  • Semantische HTML schrijven met header, nav, main, section en footer.
  • CSS opsplitsen in een apart bestand en de stijlregels daar centraal beheren.
  • Kleuren en afmetingen als CSS-variabelen definiëren en hergebruiken.
  • Een responsive grid bouwen met grid-template-columns en auto-fit.
  • Smooth scroll tussen secties regelen met JavaScript.

Hoe de website is opgebouwd

Bestand Wat erin zit
index.html De inhoud van de pagina: alle teksten en secties.
css/style.css Alle stijlregels, met de kleuren bovenaan als variabelen.
js/main.js De interactie, zoals het scrollen naar een sectie.
projecten/ Deze pagina's, een per project.
