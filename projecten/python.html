Python met Git

  • Python
  • Git
  • Versiebeheer

Wat het project was

Een Python-project waarbij ik tegelijk met het schrijven van code de versiebeheer van Git heb gebruikt. Na elke werkronde maakte ik een commit, zodat ik kon zien wat er veranderde en terug kon naar een eerdere versie als er iets misging.

Vul hier in wat het script deed: wat het programma uitvoert en waarvoor je het zou gebruiken.

Wat ik heb geleerd

  • Variabelen, lijsten en met if beslissingen nemen in Python.
  • Fouten terugvinden door de code stap voor stap te lezen en te testen.
  • Met git status zien welke bestanden gewijzigd zijn.
  • Met git add en git commit een versie vastleggen.
  • Waarom een vaste projectstructuur en versiebeheer belangrijk zijn bij teamwork.

Waarom Git erbij hoorde

Met Git kan ik niet alleen zien wat ik heb gedaan, maar ook terug naar een vorige versie. Dat is handig als ik een fout maak: in plaats van het helemaal opnieuw te typen haal ik de vorige versie terug.

Daarnaast heeft het me geholpen om te begrijpen waarom developers hun projecten in een vaste structuur zetten: het maakt het voor mijzelf en voor anderen overzichtelijk waar alles staat.
